# Pre-specified weight reading experiment

The unit of evaluation is one previously unseen prompt in one new context of the named model. Both models receive identical text for each instance. The task instructions describe input coordinates, tensor layout and activation conventions. No images, labels, training metrics or trial history are supplied to respondents.

* Recognition: Test all ten MNIST one-vs-rest targets at each of the five fixed shapes (196→1, 196→4→1, 196→32→1, 196→32→32→1, 196→128→64→1). Require one digit. A uniform guess is correct with probability 0.1. A constant guess gets exactly one of ten per fully delivered tier.
* Editing: Four independently fitted four-bit networks. Require at most two output-layer scalar replacements. Success requires all 16 binary inputs and both outputs to agree with the requested transformation to absolute tolerance 0.001. Also count matching scalar outputs. Test the unchanged model and a constructive reference edit as controls.
* Freeze all weights, labels, prompts, schedules and scoring rules before collecting responses. Both named models use medium reasoning effort. Do not adjust training or prompts after observing answers. The first validly delivered attempt is final even if its answer is malformed or incorrect.
* Model isolation: Each call uses a new subagent with no parent conversation. The only allowed tool action is displaying assigned consecutive prompt packets verbatim. No program may interpret weights, select a subset, run a network, render a diagram, use another model, or fetch another file for a respondent. Label-bearing files are shared at the filesystem level but are never authorized or passed to respondents. The task envelope and packet boundaries are transport metadata. The receipt at the end of every packet must appear in order in the reply. A truncated read may be reissued verbatim. Loss of context, unavailable transport or missing receipts is recorded separately from a wrong answer. Mention any deviations and report assigned as well as scorable denominators.
* Report per-shape counts, classifier balanced accuracy and AUROC on the official 10,000-image test set using text-roundtripped weights. Compare models on common delivered items. For the 10 distinct targets within each fully observed tier use an exact conditional permutation test (one-sided, randomize the association between fixed guesses and targets). Correct for five size tests per model using Holm. If reporting uncertainty on success fractions, identify assumptions. Do not infer a monotone parameter capacity from isolated successes.
* Size cap: The entire UTF-8/ASCII task text must fit in 300,000 bytes. For byte-based tokenization this also bounds its token count, even when every digit is a separate token. Record complete prompt size, parameter count, and a tokenizer proxy where available. Platform instructions and thought/output tokens are outside the network-text budget.

The two tasks measure successful decisions or functional edits. The outcome alone cannot demonstrate that a respondent used every parameter.
