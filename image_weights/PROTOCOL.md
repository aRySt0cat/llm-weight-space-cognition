# Weight matrices as images

Freeze this protocol and the image hashes before starting the image respondents. Compare the same 50 frozen MNIST checkpoints with the original numeric-text trials. One new context per model and checkpoint, medium effort, using gpt-6.2-astra, gpt-6.1-terra, gpt-6-luna. No carry-over, correct answers, raw weight text, inference examples or feedback. Only direct visual display of the assigned PNG is allowed. The experiment uses instruction-based isolation in a shared filesystem.

One PNG shows every layer in forward order. Output units are rows, input units are columns. A separate vertical strip gives all biases. The first matrix uses 196 consecutive columns for the row-major flattened 14×14 input, including for linear models. No spatially rearranged digit thumbnails are provided. Each layer has its own printed maximum absolute magnitude across its weights and biases. Each coefficient is rounded to the nearest of 255 signed steps on each side of white. Red means positive, blue negative. Nearest-neighbor enlargement preserves the color bins. Thus both quantization and layout change relative to the text condition, whose incoming weights wrapped every 14 entries.

Schedule in opaque ID order. Use literal child finals with no Markdown cleanup. Record only the first final per case. An eight-character visual receipt must match. A valid receipt and wrong or invalid digit count as incorrect; absent/mismatched receipt, no image or documented non-permitted tool use count as ineligible and as failures in assigned-denominator sensitivity. Any anomalous agent observed using another tool is logged explicitly. Missing receipt can be checked independently of the digit. Do not rerun a wrong, invalid or excluded final. An infrastructure dispatch that never created a respondent may be retried and documented. Check paired text/image correctness on the same eligible checkpoints for each model. Report both-correct, text-only, image-only, neither, and exact two-sided McNemar (binomial) p values with Holm correction over the three models; size groups descriptive. Compare image accuracy with 10-choice chance using a one-sided permutation test stratified by architecture, conditional on eligible targets and the model's answers, Holm over three models. No claims about a universal parameter limit.
